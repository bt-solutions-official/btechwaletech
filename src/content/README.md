# Content Collections

Content collection schemas are defined in `src/content.config.ts`.

- `blog/`: future article drafts and published articles.
- `case-studies/`: real case studies only. Do not create fake clients, fake testimonials, fake metrics, or fabricated outcomes.
- `portfolio/`: real portfolio entries only when project details and assets are ready.

Do not place README files inside collection folders because Astro treats Markdown files there as collection entries.
